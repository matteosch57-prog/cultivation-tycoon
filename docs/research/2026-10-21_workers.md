# Sect workers: how tycoons do worker NPCs (2026-10-21)

Evidence file (write once). Mock: [docs/art/mocks/workers.html](../art/mocks/workers.html). Nothing built yet.

## Sources (community fan wikis and DevForum; no first-party source on worker design)
- Restaurant Tycoon 3 (bloxodes fan wiki): staff by role (chefs, servers, baristas), each role a fixed
  number of slots (8 chefs, 8 servers, 2 baristas), hire cost rising per slot, then upgrades per slot;
  hired from a Staff menu, some roles Robux. https://bloxodes.com/wiki/restaurant-tycoon-3/workers
- Retail Tycoon 2 (fan guides): a cashier first, restockers and managers later automate tasks; staff
  you can see working is part of the fantasy. https://deltiasgaming.com/?p=249723
- Mining tycoons (Winter Mining, Clone Mining, Idle Mining Simulator listings): "hire miners" is the
  standard income upgrade, workers shown digging. https://www.sportskeeda.com/roblox-news/mining-tycoon-a-beginner-s-guide
- DevForum, many NPCs: drive visuals on the client, keep the server dumb (one controller, no script per
  NPC); a tycoon with 360 NPCs tweened them client side. https://devforum.roblox.com/t/how-bad-is-it-using-server-npcs/3145670 ,
  https://devforum.roblox.com/t/supporting-a-large-amount-of-ai/171487 , https://devforum.roblox.com/t/npc-animation-optimization/1316172

## What carries over
1. Workers are tied to a station (a building), a few slots each, price rising per slot.
2. Each hire is visible: one more figure doing a job loop at that building.
3. The job loop is short and in place (hoe, strike, fan); walking routes are rare and cost more.
4. Clients animate, the server only owns the count; stop off screen (R16).

## Proposal in the mock
- Hire pad beside each building (step-on, like all pads), up to 3 workers, +50% of that building's qi
  each (to be simmed by the economy thread before any number goes in Config).
- Plain work clothes + straw hat so workers never read as collectible disciples, and light on phones.
- First batch: Farmer (Herb Garden), Sparring pair (Training Ground), Miner (Spirit Vein), Alchemist
  (Alchemy Furnace).
