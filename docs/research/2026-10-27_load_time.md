# Load time (2026-10-27, thread "Keep new players past 10 minutes")

Owner asks: "make the loading more optimized and less long", then "have the skip always ready".

## What was slow (Studio fresh-save Plays)
- Server boot ~5 s: Creator Store meshes were fetched one by one (RankBoard lanterns fetched the same mesh 8x each). Fix: `src/server/MeshCache.luau` prefetches every Config mesh at once and clones repeats. Boot 5.0 s -> 1.0 s. Any new `CreateMeshPartAsync` call must go through `MeshCache.fetch`.
- Join web checks ran one after another: passes (`Shop.prefetch`), group and friends now run in parallel from the start of `onJoin`. Server join 0.5 s.
- Launch screen padding ~2 s: FULL_HOLD 0.5 -> 0.15, DIVE 1.6 -> 1.1, fast fill once all steps are done.
- Result: launch screen 7.3 s -> 3.1 s (was ~9 s on 2026-10-26).
- SKIP shows from the first frame (4fdeb34); pressed before the peak + avatar exist it enters the moment they do.

## Logging
- Event `LoadTime` {boot | server | enter_<last step: loaded/hud/peak/body/skip/timeout>, secBucket, device|new/return}.
- Journal codes `load:<stage>:<seconds>`; `tools/first5_report.luau` prints medians.
- Studio Output: `[Tycoon][load] server boot ...`, `server join ...`, `enter_<step> N s`.
- Reading a slow case: enter_loaded = Roblox/network; enter_peak = save/passes/build; enter_body = avatar service.
